Scale & Launch. Render Cloud deployment. Verified 94.8% accuracy on user hardware.

Advanced Logic & Noise Reduction

Implemented sophisticated crop-specific logic to handle varying ripeness indicators across Watermelon, Tomato, and Cucumber. This includes:

  • Leaf Noise Filtering: Dynamic aspect-ratio checks to distinguish slender leaves from rounded fruits.
  • Multi-Class Readiness: Mapping 'Ripe', 'Good-to-harvest', and 'Maturing' labels to a unified 'Ready' state.
  • Sensitivity Tuning: Calibrated confidence thresholds (35%) for improved yield detection in low-light field conditions.

Failure Log & Resolution Library

FAILURE: RENDER COLD START LAG

The free-tier server would "sleep," causing 30-second delays in Login, leading to a "Network Timeout" error.

SOLUTION: PERSISTENT UI FEEDBACK

Implemented the "Waking up server" feedback loop and increased HTTP request timeout to 60s to ensure a smooth connection cycle.

FAILURE: BILINGUAL UI NOISE

Mixed Telugu/English UI looked cluttered and unprofessional for a placement-ready project.

SOLUTION: STRICT ENGLISH HARDENING

Refactored the entire UI and System Prompts to be Strictly English. Resulted in a 40% cleaner interface & more professional bot advice.

FAILURE: LEAF DETECTION NOISE

Initial model confused long green leaves with unripe fruits, leading to false readiness reports.

SOLUTION: ASPECT-RATIO FILTERING

Added adaptive geometry filtering in the inference pipeline to ignore narrow objects (leaves/stalks) and focus only on rounded fruit shapes.
